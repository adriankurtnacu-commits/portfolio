# Adrian Nacu — Portfolio

Static portfolio site for GitHub Pages. It uses plain HTML, CSS, and vanilla JavaScript, so no build step or package installation is required.

## Publish on GitHub Pages

1. Create a GitHub repository and upload the contents of this folder.
2. In **Settings → Pages**, choose **Deploy from a branch**.
3. Select the default branch and the `/ (root)` folder, then save.

The PDF resume links and project screenshots are stored in `assets/`.
